📋 完整步骤拆解

① 浏览器登录

  • 用户从 Chrome DevTools Application → Cookies 复制 auth_token
  • Hermes 通过 document.cookie 注入浏览器
  • 绕过 OAuth/密码，直接用已有登录态
  • 坑：document.cookie 拿不到 httpOnly 的 token

② 页面滚动 + 数据提取

  • browser_scroll 重复滚动加载帖子
  • browser_console 执行 JS 提取 meta 标签数据
  • 从 itemprop="articleBody" 拿正文
  • 从 aria-label 拿互动数据
  • 坑：Highlights 页只有30条，需切到 Posts 页

③ 过滤 + 翻译 + 标签

  • Python 脚本筛选含泰语疑问词的帖子
  • LLM 逐条翻译泰语→中文
  • 按主题打双语标签（#情感 #ความรัก）
  • 去重、按日期排序

④ 配图生成

  • HTML + CSS 设计 7 种风格卡片
  • puppeteer 逐个截图 → PNG
  • 900×1200（3:4 社媒最佳尺寸）
  • 纯泰语，无标签，无中文

🤖 自动化方案

方案A：Hermes Cron 定时任务

最快上线，零开发。创建一个定时任务，每天自动检查博主新帖。

cronjob create "每天检查 @m4ilboq 新帖，如有新提问帖则翻译+打标签" --schedule "0 9 * * *"

优点：直接用现有工具 | 缺点：每次都需登录态刷新

方案B：Feishu 机器人 + 飞书表格

通过飞书开放平台 + Webhook 实现：

  • 用户在飞书群发送博主链接
  • 机器人调用 Hermes API 抓取
  • 结果写入飞书多维表格
  • 群内推送新帖通知

优点：团队协作 | 缺点：需开发飞书应用

方案C：网页工具（Web App）

部署一个简单的页面：

  • 输入 X 博主链接 → 选择过滤条件
  • 后端调用 Hermes / Puppeteer
  • 输出 HTML 预览 + 一键下载 ZIP

优点：最灵活 | 缺点：需服务器
