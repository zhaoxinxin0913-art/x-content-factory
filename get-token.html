🔐 获取 Auth Token

只需要做一次，以后都填同一个

1

打开 X 并登录

点下方按钮跳转 X，确保已经登录你的账号

2

打开开发者工具

Mac 按 ⌘+Option+I，Windows 按 F12

3

找到 auth_token

顶部标签选 Application → 左侧找到 Cookies → 点 x.com → 在右侧列表找到 auth_token，双击 Value 复制

🚀 打开 X
⬇️

复制 auth_token 后，回到这里粘贴 👇

✅ 检测到 Token！复制这个值，回到内容工厂粘贴使用
💡 温馨提示
Token 是你的 X 登录凭证，相当于密码。不要发给别人。每个同事用自己账号的 token，安全不封号。
