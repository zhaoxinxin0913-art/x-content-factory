🔐 Token Helper 扩展 — 安装教程

第 1 步：下载扩展文件

扩展文件已在项目的 extension/ 目录中。从 GitHub 克隆项目或直接复制文件夹即可：

git clone https://github.com/zhaoxinxin0913-art/x-content-factory.git

第 2 步：打开 Chrome 扩展管理页

在 Chrome 地址栏输入：chrome://extensions

第 3 步：加载已解压的扩展

1. 打开右上角「开发者模式」开关

2. 点击「加载已解压的扩展程序」

3. 选择项目中的 extension/ 文件夹

第 4 步：使用

打开 X 内容工厂页面，在 Token 输入框上方会出现「🔐 一键授权」按钮。点一下即可自动填入 auth_token。

前提：你在 Chrome 中已登录 x.com
